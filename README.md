# أرنوبة 🐇📚

مكتبة كتب مجانية: الزائر يتصفح الكتب العربية والإنكليزية (كل لغة بقائمة منفصلة)، يقرأها داخل الموقع أو يحمّلها PDF وEPUB، بدون حسابات.

## الميزات

- **قائمتان منفصلتان**: `/ar` للكتب العربية و`/en` للإنكليزية، مع تصنيفات وترتيب (الأكثر قراءة، الأحدث، العنوان).
- **بحث يفهم العربي**: لا يفرّق بين أ/إ/آ/ا، ة/ه، ى/ي، ويتجاهل التشكيل والتطويل، وكلمة «الحمامة» تجد «حمامة».
- **قارئ داخل الموقع**: PDF (تمرير مستمر وتكبير) وEPUB (صفحات تُقلب من اليمين لليسار للكتب العربية، فهرس، تكبير خط، سحب بالإصبع على الموبايل)، بثلاثة مظاهر: فاتح، ورقي، ليلي. ويتذكر أين توقفت.
- **رفّي** و**تابع القراءة**: محفوظة في متصفح الزائر فقط (لا حسابات ولا بيانات شخصية على الخادم).
- **كتب عربية كاملة بأغلفتها**: أكثر من 500 رواية وقصة (خيال علمي، بوليسية، تاريخية، سِيَر ورحلات، مسرح) من مؤسسة هنداوي، كلها نسخ كاملة برخصة CC BY 4.0. الكتب التي ليس لها غلاف يُرسم لها غلاف تلقائياً.
- **شارة «نسخة كاملة»** على الكتب التي تأكدنا أنها كاملة، و**«حكايات صارت أفلاماً»**: قسم للكتب التي تحولت إلى أفلام مع اسم الفيلم.
- **لوحة تحكم** `/admin`: رفع كتب (تستخرج العنوان والمؤلف وعدد الصفحات والغلاف من الملف تلقائياً)، تعديل، إخفاء، حذف، واستيراد بضغطة من مؤسسة هنداوي وProject Gutenberg وويكي مصدر، ومتابعة البلاغات.
- **بلاغات**: زر «إبلاغ عن مشكلة» في كل كتاب (حقوق نشر، كتاب ناقص، ملف تالف…).
- **SEO**: صفحة لكل كتاب مع وصف وبيانات Schema.org وخريطة موقع.
- **وضع ليلي** للموقع كله، وتصميم يناسب الموبايل.

## التشغيل على جهازك

يحتاج Node.js 22.13 أو أحدث.

```bash
npm install
npm run dev
```

ثم افتح http://localhost:3000. لا تحتاج قاعدة بيانات ولا تخزيناً سحابياً محلياً:

- قاعدة البيانات PostgreSQL مدمجة (PGlite) تُحفظ في مجلد `.data/`.
- ملفات الكتب تُحفظ في مجلد `storage/`.

**لوحة التحكم:** كلمة السر في ملف `.env.local` (المتغير `ADMIN_PASSWORD`). إذا لم يكن الملف موجوداً، انسخ `.env.example` إلى `.env.local` واكتب كلمة سر وقيمة عشوائية لـ `SESSION_SECRET`.

**تعبئة المكتبة بكتب مبدئية:** (أوقف `npm run dev` أولاً، لأن القاعدة المدمجة تُفتح من برنامج واحد فقط)

```bash
npm run seed                    # 27 كتاباً عربياً من ويكي مصدر + 30 كتاباً إنكليزياً
npm run seed -- --hindawi       # 554 كتاباً عربياً كاملاً من مؤسسة هنداوي (حوالي 1.5 غيغابايت، يكمل من حيث توقف)
npm run seed -- --covers        # يرسم غلافاً لكل كتاب عربي بلا غلاف
npm run seed -- --prune         # يحذف كتب ويكي مصدر التي تبيّن أنها ناقصة أو استُبدلت بنسخة هنداوي
npm run seed -- --english=100   # عدد آخر من الكتب الإنكليزية
npm run seed -- --arabic-only
npm run seed -- --english-only --english=40 --topic=fantasy   # حسب النوع
npm run seed -- --picks          # 48 كلاسيكية مختارة: ساحر أوز، آلة الزمن، حكايات غريم وأندرسن…
npm run seed -- --ids=55,16,35   # كتب محددة برقمها في Gutenberg
```

الأنواع المتاحة لـ `--topic`: `fantasy` و`"science fiction"` و`"fairy tales"` و`adventure` و`detective` و`horror` و`children` و`history` و`philosophy` و`poetry`.
نفس الاستيراد (مع اختيار النوع) متوفر من لوحة التحكم في صفحة «استيراد».

| المصدر | الرخصة | ملاحظات |
| --- | --- | --- |
| Project Gutenberg (إنكليزي) | ملكية عامة | المستورد يتجاوز تلقائياً أي كتاب مؤلفه أو مترجمه توفي بعد (السنة الحالية − 71)، ليكون في الملكية العامة في دول «حياة المؤلف + 70» وليس في أمريكا فقط. |
| مؤسسة هنداوي (عربي) | CC BY 4.0 للطبعة كلها (النص والترجمة والغلاف) | المستورد يقرأ صفحة الحقوق داخل كل كتاب، ولا يأخذ الكتاب إلا إذا كانت الطبعة كلها CC BY 4.0 والأصل في الملكية العامة **و**صدر الأصل (وأي ترجمة قديمة) قبل (السنة الحالية − 95)، أي في الملكية العامة في أمريكا حيث الاستضافة وفي الدول العربية. الكتب «المحفوظة الحقوق» أو «غير التجارية» تُترك تلقائياً، حسب [أسئلتهم المتكررة](https://www.safahat.org/faqs/). |
| ويكي مصدر (عربي) | النص ملكية عامة، والنسخة الرقمية CC BY-SA (وبعض الترجمات CC BY 4.0) | المصدر والرخصة يظهران في صفحة كل كتاب مع رابط الصفحة الأصلية. أُزيلت النصوص التي تبيّن أن تفريغها ناقص. |

لا ترفع كتاباً محمياً بحقوق النشر بدون إذن مكتوب. البلاغات تصلك في `/admin/reports`، وزر «إخفاء الكتاب» يخفيه فوراً.

**لا تنقل من مواقع يرفع عليها المستخدمون الكتب** (مثل «مكتبة نور» و«فولة بوك» وأمثالها): حتى لو كان الكتاب منشوراً هناك بإذن صاحبه، فالإذن لذلك الموقع وليس لموقعك، وأغلب الكتب الحديثة فيها محمية بحقوق النشر. وكذلك المنصات التي تتيح القراءة مجاناً (مثل «أبجد» و«رشف» و«عصير الكتب»): القراءة المجانية عندهم ليست إذناً بإعادة النشر.

## النشر على الإنترنت (مجاناً للبداية)

الإعداد المقترح: **Vercel** للموقع + **Neon** لقاعدة البيانات + **Cloudflare R2** للملفات (R2 لا يأخذ رسوماً على التحميل، وهذا أهم شيء لموقع كتب).

1. **قاعدة البيانات:** أنشئ مشروعاً في [Neon](https://neon.tech) وانسخ رابط الاتصال (Pooled connection) إلى `DATABASE_URL`. الجداول تُنشأ تلقائياً عند أول تشغيل.
2. **التخزين:** في Cloudflare R2 أنشئ Bucket، وفعّل الوصول العام (Custom Domain أو r2.dev) وضع رابطه في `S3_PUBLIC_URL`. أنشئ API Token بصلاحية «Object Read & Write» وضع قيمه في `S3_ACCESS_KEY_ID` و`S3_SECRET_ACCESS_KEY`، و`S3_ENDPOINT=https://<ACCOUNT_ID>.r2.cloudflarestorage.com`، و`S3_BUCKET` اسم الـ Bucket.
3. **CORS للـ Bucket** (ضروري للقارئ ولرفع الكتب من لوحة التحكم):

   ```json
   [
     {
       "AllowedOrigins": ["https://your-domain.com"],
       "AllowedMethods": ["GET", "HEAD", "PUT"],
       "AllowedHeaders": ["content-type", "content-disposition", "range"],
       "ExposeHeaders": ["accept-ranges", "content-range", "content-length", "etag"],
       "MaxAgeSeconds": 3600
     }
   ]
   ```

4. **Vercel:** ارفع المشروع إلى GitHub واستورده في Vercel، وأضف متغيرات البيئة كلها من `.env.example` (`SITE_URL` = رابط موقعك، و`ADMIN_PASSWORD` و`SESSION_SECRET` قيم جديدة قوية غير قيم جهازك).
5. **تعبئة الكتب على الموقع المنشور:** من لوحة التحكم ← استيراد، أو من جهازك بعد وضع متغيرات الإنتاج في `.env.local`: `npm run seed`.

6. **الظهور في Google:** في [Google Search Console](https://search.google.com/search-console) أضف موقعك بطريقة «URL prefix»، واختر التحقق بـ «HTML tag»، وضع القيمة التي داخل `content="..."` في متغير `GOOGLE_SITE_VERIFICATION` على Vercel ثم أعد النشر واضغط «Verify». بعدها من «Sitemaps» أضف `sitemap.xml`.

> بدون `DATABASE_URL` و`S3_*` يرفض الموقع العمل على Vercel برسالة واضحة، لأن Vercel لا يحتفظ بالملفات على القرص.

## الأمان

**الدخول إلى لوحة التحكم**
- جلسات على الخادم: الكوكي يحمل رمزاً عشوائياً (256 بت) وقاعدة البيانات تخزّن بصمته فقط (SHA-256)، فتسريب القاعدة لا يعطي جلسات صالحة.
- الكوكي باسم `__Host-` مع `Secure` و`HttpOnly` و`SameSite=Strict`. الجلسة تنتهي بعد 12 ساعة، أو بعد ساعتين بلا نشاط.
- «تسجيل الخروج» يحذف الجلسة من الخادم، و«تسجيل الخروج من كل الأجهزة» يبطل حتى الكوكي المسروقة. وتغيير `ADMIN_PASSWORD` يُخرج الجميع.
- حظر بعد 5 محاولات خاطئة من نفس العنوان خلال 15 دقيقة، ويشمل الحظر كلمة السر الصحيحة أيضاً. والعدّاد في قاعدة البيانات، فيعمل حتى مع عدة نسخ من الخادم. ومع هجوم موزّع يبطؤ الدخول للجميع بدل قفل المشرف الحقيقي.
- اختياري: `ADMIN_ALLOWED_IPS` يحصر لوحة التحكم بعناوين محددة، وتظهر لغيرها صفحة 404.
- كل صفحة وإجراء ومسار إداري يتحقق من الجلسة بنفسه، ولا يعتمد على الـ proxy.

**سجل الأحداث:** محاولات الدخول، والحظر، والملفات المرفوضة، وإضافة الكتب وحذفها، والبلاغات، كلها تظهر في قسم «الأمان» بالصفحة الرئيسية للوحة التحكم، وتُحفظ 90 يوماً.

**الحماية من حقن السكربتات (XSS)**
- سياسة CSP لكل صفحة برقم عشوائي جديد (nonce) مع `strict-dynamic`، بدون `unsafe-inline` للسكربتات، فأي سكربت مُحقن لا يعمل.
- إضافة لـ `object-src 'none'` و`base-uri 'none'` و`frame-ancestors 'none'`، ومنع تضمين الموقع داخل إطار.
- قارئ EPUB يعرض الكتاب داخل iframe معزول بلا سكربتات، والروابط الخارجية تقبل http/https فقط.

**الملفات**
- كل ملف مرفوع يُفحص من محتواه الفعلي (Magic bytes)، لا من اسمه أو النوع المعلن.
- ملفات PDF التي تحوي JavaScript أو أوامر تشغيل (Launch) أو ملفات مضمّنة تُرفض، والفحص يكشف الأسماء المموّهة مثل `/J#61vaScript`.
- ملفات EPUB التي تحوي سكربتات أو روابط `javascript:` أو ملفات تنفيذية تُرفض، ويشمل هذا الكتب المستوردة.
- ملفات الكتب تُرسل دائماً كمرفقات للتحميل، مع `CSP: sandbox`، فلا تُفتح كصفحة على نطاق الموقع. وأسماؤها في التخزين UUID يولّدها الخادم.

**الطلبات والترويسات**
- حدود لكل عنوان IP على التحميل (40 في الدقيقة) والبحث (60 في الدقيقة) والبلاغات.
- عناوين IP تُقرأ من الترويسات فقط خلف وسيط موثوق: Vercel، أو `TRUST_PROXY=1` خلف nginx يضبط `X-Real-IP`، لأن العميل يستطيع تزوير هذه الترويسات.
- ترويسات أمان: HSTS وX-Frame-Options وCOOP وCORP وPermissions-Policy وReferrer-Policy وnosniff.
- استعلامات قاعدة البيانات كلها بمعاملات (parameterized)، وأعمدة الترتيب من قائمة ثابتة. و`npm audit` بلا ثغرات.

## التقنيات

Next.js 16 (App Router) وReact 19 وTailwind CSS 4 وPostgreSQL (`pg` أو PGlite) وpdf.js وepub.js وCloudflare R2 عبر `aws4fetch`.

```
src/app/(site)      الصفحات العامة: الرئيسية، /ar، /en، البحث، الكتاب، رفّي، البلاغ
src/app/read        القارئ (بدون هيدر الموقع)
src/app/admin       لوحة التحكم
src/app/api         التحميل، عدّاد القراءة، رفع الملفات
src/lib             قاعدة البيانات، التخزين، البحث العربي، الاستيراد، الجلسات
src/components      الواجهة والقارئ ونماذج لوحة التحكم
```
